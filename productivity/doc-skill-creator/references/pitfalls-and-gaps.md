# pitfalls-and-gaps

## Purpose

Track weak points in both the source material and the resulting target skill.

## Pitfalls

Common areas to watch:

- assuming examples imply official guarantees
- treating inferred guidance as documented fact
- over-scoping the skill
- forcing unsupported troubleshooting ability
- forcing migration ability without real mapping
- creating too many references files for too little material

## Gap categories

### Missing scenarios
Weakens recommendation ability.

### Missing examples
Weakens generation ability.

### Missing FAQ or issue patterns
Weakens troubleshooting ability.

### Missing migration notes
Weakens upgrade assistance.

### Missing rules or conventions
Weakens decision support and standards enforcement.
