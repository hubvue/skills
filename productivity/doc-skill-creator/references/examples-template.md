# examples-template

## Purpose

Define how example material should be turned into reusable output patterns for the target skill.

## Example categories

### 1. Minimal example
Shows the smallest workable usage.

### 2. Scenario example
Shows how to solve a common user task.

### 3. Integration example
Shows how the feature connects to surrounding setup or workflow.

### 4. Migration example
Shows old vs new usage.

### 5. Troubleshooting example
Shows a mistake and a corrected version.
