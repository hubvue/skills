# migration-guide

## Purpose

Guide migration-related conversion when the source material contains upgrade or replacement information.

## Use this file when

Use this only if the docs contain meaningful migration content such as:

- version upgrade notes
- old vs new mapping
- deprecations
- replacements
- breaking changes

## Extract
