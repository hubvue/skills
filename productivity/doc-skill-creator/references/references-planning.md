# references-planning

## Purpose

Plan the references structure for the target skill.

## Default file set

Use only the files the target skill actually needs.

Recommended starting set:

- source-analysis
- capability map
- facts
- rules
- scenarios
- examples
- pitfalls
- migration
- gaps

## Planning rule

### Keep a file when:
- the target skill clearly needs that knowledge type
- the source material supports it
- separating it improves maintainability

### Omit or merge a file when:
- the source material is too small
- the knowledge type is barely present
- splitting would create empty or redundant files

## Common compact layouts

### Minimal layout

Prefer a compact structure over an impressive but bloated one.
