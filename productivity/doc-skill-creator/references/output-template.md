# output-template

## Purpose

Provide a default structure for the output produced by doc-skill-creator.

## Default response order

1. Source material analysis
2. Suitability judgment
3. Recommended target skill type
4. Target skill definition
5. Capability map
6. Knowledge-layer breakdown
7. Suggested references structure
8. Draft SKILL.md
9. Gaps and follow-up suggestions

## Rule

Keep the output practical.
A usable draft is better than a long theoretical writeup.
