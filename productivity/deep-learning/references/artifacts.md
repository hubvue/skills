# Learning Artifacts

When useful, produce one or more of these artifacts in plain text:
- architecture map
- module responsibility list
- call-chain trace
- simplified pseudocode
- lifecycle timeline
- key type / data-structure notes
- interview-ready summary
- next-reading checklist

## Artifact Selection Suggestions

### For project mode
Prefer:
- architecture map,
- module responsibility list,
- main flow trace,
- next-reading checklist.

### For module mode
Prefer:
- module responsibility summary,
- internal flow trace,
- key type notes,
- interview-ready summary.

### For function mode
Prefer:
- call-chain trace,
- simplified pseudocode,
- branch/edge-case notes,
- concise takeaways.
