# Scenario Restore Research Policy

## Default Research Depth

`standard`

## Search Guidance

- 用户现在如何完成任务
- 竞品如何设计流程
- 用户在哪些步骤抱怨最多
- 哪些场景出现频率最高

## Required Research Plan

Before calling Web Search, write a short plan with:

- current stage goal
- known information from upstream documents
- questions to verify
- search keywords
- preferred source types
- expected decision impact

## Preferred Source Types

- official_doc
- competitor
- community_discussion
- user_review
- technical_doc
- open_source_project
- industry_report
- market_data
- policy_or_regulation

## Evidence Handling

Every source used for a conclusion must be summarized into:

- key finding
- source type
- credibility
- usedIn files
- retrievedAt timestamp

Then update `sources/sources.json`.
