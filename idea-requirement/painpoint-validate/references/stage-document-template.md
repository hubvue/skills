# Stage Document Template

每个阶段文档必须包含以下结构。

```markdown
# 阶段名称

## 1. 阶段目标

这个阶段要解决什么问题？

## 2. 输入来源

本阶段读取了哪些上游文档和 research 文档？

## 3. 已知信息

从上游文档中提取到的关键信息。

## 4. 外部信息检索

本阶段是否检索、检索了什么、来源是什么。

## 5. 分析过程

本阶段如何分析，关键判断逻辑是什么。

## 6. 阶段产物

本阶段得出了什么结论和结构化产物。

## 7. 缺失信息

还有哪些信息不足？

## 8. 风险与不确定性

有哪些风险、假设和不确定性？

## 9. Evidence Block

引用 evidence-block.md。

## 10. 阶段结论

- status: passed / need_more_info / blocked / rejected
- decision: continue / revise / need_data / stop
- evidenceLevel: high / medium / low

## 11. 下游输入

下一个阶段应该重点读取什么？
```
