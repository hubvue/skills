# Evidence Block Template

每个阶段文档必须包含 Evidence Block，用于记录是否检索、检索了什么、证据如何影响判断。

```markdown
## Evidence Block

### 本阶段是否调用 Web Search

是 / 否

### 调用原因

说明为什么需要或不需要检索。

### 检索问题

- 问题 1
- 问题 2
- 问题 3

### 信息来源

| 编号 | 来源名称 | 类型 | 链接 | 可信度 | 关键发现 |
|---|---|---|---|---|---|

### 事实

- 来自外部资料或用户明确输入的事实。

### 推断

- 基于事实做出的判断。

### 假设

- 暂时缺少证据、后续需要验证的内容。

### 证据充分度

高 / 中 / 低

### 对本阶段结论的影响

说明这些外部信息如何改变、增强或削弱本阶段结论。
```

## 事实 / 推断 / 假设区分

- 事实：可以被来源、数据、用户输入直接验证。
- 推断：基于多个事实得出的判断，需要说明逻辑。
- 假设：当前无法验证，但为了推进方案临时采用。
