# Resume Project Description Templates

## Template: Backend Service

```
[Built/Developed/Engineered] [system/service name] using [tech stack]
- Designed and implemented [core feature], achieving [specific outcome]
- Scaled system to handle [X] requests/second with [Y] ms latency
- Integrated with [external systems/APIs] using [protocols/patterns]
- Implemented [specific architecture pattern] to improve [metric]
```

## Template: Frontend Application

```
[Built/Developed] [app name] using [framework] and [styling]
- Implemented [core UI/UX features] using [patterns/libraries]
- Optimized rendering performance, reducing [metric] by [X]%
- Integrated with [backend services] using [API patterns]
- Ensured [accessibility/cross-browser/mobile] compatibility
```

## Template: ML/AI Project

```
[Built/Developed] [model/system] for [use case]
- Designed and trained [model architecture] on [X] samples, achieving [Y] accuracy
- Implemented [training pipeline] with [features: data augmentation, hyperparameter tuning, etc.]
- Deployed model using [deployment strategy], achieving [inference latency/throughput]
- Evaluated model performance using [metrics] and improved [metric] by [X]%
```

## Template: System/Infrastructure

```
[Built/Engineered] [system/infrastructure] for [purpose]
- Designed [architecture] using [tech stack], achieving [scalability/reliability metrics]
- Implemented [CI/CD/monitoring/logging] using [tools]
- Scaled system to handle [X] concurrent users/[Y] data volume
- Reduced deployment time/cost by [X]% through [specific changes]
```

## Template: Library/Tool

```
[Built/Developed] [library/tool name] for [purpose]
- Designed [API/interface] following [design principles], used by [X] users/projects
- Implemented [core algorithms/functionality] with [specific optimizations]
- Ensured [quality through testing/documentation/coverage]
- Published to [registry/platform] with [X] downloads/stars
```

## Weak Verbs to Avoid

- "Responsible for"
- "Participated in"
- "Worked on"
- "Helped with"
- "Contributed to"
- "Involved in"

## Strong Action Verbs

- Built / Designed / Engineered / Developed / Created
- Implemented / Integrated / Deployed / Delivered
- Optimized / Improved / Accelerated / Streamlined
- Scaled / Architected / Structured / Designed
- Led / Drove / Spearheaded (only if true)
- Analyzed / Evaluated / Refactored / Migrated

## Effective Resume Formula

**Action + What + How + Outcome**

Examples:
- "Built REST API handling 10K RPS with <50ms latency using Go and PostgreSQL"
- "Optimized data pipeline reducing processing time by 40% through parallelization"
- "Designed microservice architecture enabling independent deployment of 15 services"
